# Сказка-цепочка

Малыш обожает предсказуемость: он знает, что будет дальше, и радостно подхватывает фразу. Сюжет строится на накоплении: одно дело, к которому по очереди присоединяются новые герои.

## Структура
1. **Задача.** Одна простая цель (вытащить, донести, построить, согреть, найти).
2. **Первый герой пробует — не получается** (или его одного мало).
3. **Звено за звеном.** Зовут следующего — и он приходит. Всего 4–6 звеньев.
4. **Формула.** Каждое звено описывается одной и той же фразой с одним меняющимся словом: «Позвала Машина зайчонка. Зайчонок за Машу, Маша за ёжика… тянут-потянут». Формула не должна меняться между звеньями.
5. **Последний, самый маленький помощник** оказывается решающим.
6. **Общий финал.** Всё получилось, все вместе празднуют, делятся.

## Приёмы
- Звукоподражания и движения (топ-топ, тянем-потянем, бух-бух): ребёнок может повторять их руками.
- Каждый новый герой — с яркой чертой (голос, шаг, звук).
- Ребёнок по имени — один из помощников (чаще всего тот, кто догадывается позвать следующего).
- Предложения короткие, 5–8 слов, ритм ровный.

## Нельзя
- Угроз и страшных героев; один из героев не должен быть «плохим».
- Неожиданных поворотов и нового сюжета в середине.
- Менять формулу. Для малыша повтор — главное удовольствие.
