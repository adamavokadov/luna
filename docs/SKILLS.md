# Навыки (skills): как устроены и как добавить свой

Навык — это папка с файлом `SKILL.md`: методика написания сказки определённого формата. Формат файла соответствует открытой спецификации [Agent Skills](https://agentskills.io/specification), поэтому навыки переносимы между совместимыми системами.

> **Навыки-компаньоны.** Не всякий навык — формат сказки. «Тёплые слова» Луны (`src/skazki_bot/cheer/skills/cheer/SKILL.md`) используют тот же формат файла, но свой валидатор (`cheer/skill.py`) и никогда не попадают в каталог навыков для модели, в меню форматов и в `make skills-check`. Подробнее: [CHEER.md](CHEER.md).

```
src/skazki_bot/skills/
└── metaphorical/
    ├── SKILL.md                  ← frontmatter + инструкции
    └── references/               ← необязательно: подробности «по требованию»
        ├── metaphors.md
        └── sensitive-topics.md
```

## Прогрессивное раскрытие

| Уровень | Что | Где живёт | Когда попадает в контекст модели |
|---|---|---|---|
| 1 | `name` + `description` (до 300 символов) | каталог в системном промпте | всегда |
| 2 | тело `SKILL.md` | — | когда навык выбран: родитель нажал в меню (тело подставляется сразу) или модель вызвала `load_skill` (авто-режим) |
| 3 | `references/*.md` | — | только если модель сама вызвала `read_skill_file` |

Поэтому 14 навыков стоят в системном промпте всего ~6,5 тыс. символов (правила + каталог), а тела грузятся по необходимости.

## Формат `SKILL.md`

```markdown
---
name: bedtime                      # строчные буквы, цифры, дефисы; совпадает с именем папки
description: "Что делает навык и когда его выбирать (до 300 символов)."
allowed-tools: get_recent_tales    # необязательно: инструменты, доступные при явном выборе
metadata:                          # собственные поля проекта (значения — строки)
  title: "Сказка на ночь"          # подпись кнопки
  emoji: "🌙"
  min-age: "2"                     # по умолчанию 2
  max-age: "10"                    # по умолчанию 10
  bedtime-ok: "true"               # годится для режима «сказка на ночь» (по умолчанию true)
  overlay: "true"                  # можно накладывать поверх другого формата (тон/ритм)
  menu: "true"                     # показывать в меню форматов (false — скрытый, как classic)
  input: "none"                    # none | optional | required — нужна ли тема от родителя
  input-prompt: "О чём сказка?"    # вопрос родителю (если input != none)
  presets: "Тема 1|Тема 2"         # быстрые кнопки тем, до 8 шт. по 40 символов, через «|»
  length-factor: "0.9"             # множитель объёма (0.2–2.0)
  parent-note: "false"             # true → в конце «Для родителей»; проверяется guard-слоем
  order: "5"                       # порядок в меню
---
# Тело: инструкции модели (до 500 строк)
```

Что проверяет загрузчик (и CI): имя и папка совпадают; нет полей вне спецификации; описание не пустое и ≤300 символов; допустимые типы в `metadata`; `min-age ≤ max-age`; у `input: required` есть вопрос или пресеты; `allowed-tools` из известных; тело не пустое и ≤500 строк; все упомянутые `references/…` существуют.

## Инструменты агента

| Инструмент | Что делает | Когда доступен |
|---|---|---|
| `load_skill(name)` | отдаёт тело навыка (только подходящие по возрасту и режиму; максимум 2 за сказку) | авто-режим |
| `read_skill_file(name, path)` | читает файл из `references/` загруженного навыка (белый список путей, без `..`) | авто-режим; при явном выборе — если у навыка есть `references/` |
| `pick_classic(count, theme)` | подбирает сюжеты-основы с учётом возраста, интересов и уже рассказанного | авто-режим |
| `get_recent_tales(limit)` | недавние сказки ребёнка: название, формат, оценка, начало | авто-режим; при явном выборе — если указан в `allowed-tools` |

При явном выборе формата действует **принцип наименьших привилегий**: навык без `allowed-tools` и без `references/` выполняется за один ход вообще без инструментов.

## Наложения (overlay)

Навык с `overlay: "true"` можно включить поверх любого другого формата. Сейчас так работает `bedtime`: кнопка «🌙 Сказка на ночь» применяет его ритм и концовку к выбранному формату. Пишите тело такого навыка двояко: «как основной формат…» и «как наложение…».

## Раздел «Для родителей»

Если `parent-note: "true"`, модель добавляет после сказки строку `=== ДЛЯ РОДИТЕЛЕЙ ===` и 2–4 предложения; бот отправляет их отдельным сообщением. Без раздела guard-слой потребует доработку. В теле навыка опишите, что именно туда писать.

## Свои навыки без правки кода

1. Создайте папку навыков, например `my-skills/`, и в ней подпапку `my-format/SKILL.md`.
2. Проверьте: `make skills-check dir=./my-skills`.
3. Укажите `SKILLS_DIR=./my-skills` в `.env` и перезапустите бота. Навык с именем встроенного перекрывает его.
4. Оцените качество: `make eval skill=my-format` (с `LLM_PROVIDER=anthropic` тратит реальные токены).

## Советы по написанию

- Пишите **методику**, а не пожелания: структура по шагам, приёмы, что нельзя, различия по возрасту.
- Одна идея — один навык. Чем уже описание, тем точнее модель выберет его в авто-режиме.
- Всё, что нужно почти каждый раз, держите в теле; в `references/` — каталоги и редкие подробности.
- Не дублируйте общие правила (безопасность, язык, род) — они уже в системном промпте.
- Любое «нельзя» подкрепляйте тем, что делать вместо этого.
